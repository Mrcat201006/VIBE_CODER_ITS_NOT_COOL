# AniTracker — Sunset redesign

## Что изменено
- Новое оформление в настроении референса: тёмное бирюзовое небо, тёплые персиковые акценты и фото облаков в шапке.
- Сохранены каталог, поиск, фильтры, сортировка, сетка/таблица, статистика, редактирование, удаление и отслеживание серий.
- Категории расширены: аниме-сериал, аниме-фильм, сериал, фильм, мультфильм и мультсериал. Новые категории доступны при добавлении/редактировании и в фильтре списка.
- При нажатии на карточку «Всего тайтлов» открывается компактная разбивка общего количества записей по типам: «Фильмы», «Аниме» (аниме-сериалы + аниме-фильмы), «Мультики» (мультфильмы + мультсериалы) и «Сериалы». Счётчики включают все записи независимо от статуса и не зависят от фильтров каталога. Подтипы по-прежнему остаются раздельными в форме и фильтре. Если в импортированных данных встречаются неизвестные типы, они показываются в дополнительной группе «Другие».
- Импорт и экспорт JSON сохранены.
- Оценка теперь вводится с шагом `0.1` по шкале `0–10`. Примеры: `8.7`, `9.2`, `10.0`. На сайте дробная часть отображается через запятую.
- Используется прежний ключ LocalStorage `aniTracker_items`, поэтому существующие записи в том же браузере не должны пропасть.

## Как обновить GitHub Pages
1. Перед заменой файлов открой старый сайт и сделай **Экспорт JSON** на всякий случай.
2. Загрузи в корень репозитория новые `index.html`, `style.css` и `app.js`.
3. Обязательно загрузи папку `assets` с файлом `cloudscape.jpg`.
4. Дождись публикации GitHub Pages и обнови сайт. При старом кэше попробуй `Ctrl + F5`.

Существующие записи хранятся в LocalStorage браузера. JSON-экспорт остаётся резервной копией, а не серверной синхронизацией между разными устройствами.
